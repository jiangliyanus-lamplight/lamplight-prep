# Lamplight Prep | Founded by Ms Jiang

**专注学生活动规划 Student Activity Planning Studio**

Lamplight Prep is an independent student activity planning studio founded by Ms Jiang, dedicated to youth leadership and sustainable development project-based learning.

Led students from Grade 7 to undergrad to complete entirely student-run projects, covering environment, health, education equity, and youth leadership.
